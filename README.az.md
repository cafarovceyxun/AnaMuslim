Quranı azərbaycanca tərcümə, sözbəsöz təhlil, təcvid rəngləri və 16 qari ilə oxu,
dinlə, axtar və öyrən — yanında ərəbcə/azərbaycanca hədis kitabxanası ilə.
Məzmun bir dəfə yükləndikdən sonra hər şey internetsiz işləməyə davam edir.

Reklam yoxdur. Analitika SDK-ları yoxdur. Bir kəlmə oxumaq üçün belə hesab tələb
olunmur.

> **AnaMuslim** — [**AlfaazPlus-un QuranApp**](https://github.com/AlfaazPlus/QuranApp)
> tətbiqinin müstəqil fork-udur, GNU General Public License v3.0 altındadır.
> İstinad və dəyişikliklərin xülasəsi: [NOTICE](NOTICE).

### Quran oxuyucusu

- Dörd oxuma düzülüşü: ayə-ayə, mushaf (səhifə-səhifə), tərcümə və şaquli tərcümə
- Surə, cüz, hizb və səhifə üzrə naviqasiya
- Ərəb xətləri: Osmanlı, KFQPC v1, KFQPC v2, KFQPC v4 (təcvid) və Hind-Pak
  (15 və 16 sətirli variantlar); KFQPC səhifə şriftləri tələb üzrə yüklənir
- Osmanlı xəttində təcvid rəngləri
- Sözbəsöz mənalar (ingilis, rus və türk söz paketləri; transliterasiya
  ingiliscədə) və hər söz üçün ərəbcə səsləndirmə
- Ərəb mətni tamamilə söndürülə bilər (yalnız tərcümə oxumaq üçün); ərəbcə və
  tərcümə mətn ölçüləri bir-birindən asılı olmadan tənzimlənir
- Surə haqqında səhifələri, "bənzər ayələr" axtarışı və ayə istinadına sürətli baxış
- Avto-sürüşmə, səs / səhifə / S Pen düymələri ilə səhifə çevirmə, landşaft və
  planşet düzülüşləri

### Tərcümə

- Azərbaycanca Quran tərcüməsi (Mürşüd Yusifoğlu), ayə üzrə qeydlərlə; layihənin
  öz backend-indən yüklənir və oflayn oxunur
- Tərcüməçi mötərizələrini gizlət və ya işıqlandır
- Ayədə və ya tərcümədə səhvi birbaşa oxuyucudan bildir; moderatorlar tətbiq
  daxilində baxıb düzəldir və düzəliş bütün istifadəçilərə çatır

### Hədis

- Hədis kitabxanası cild → kitab → bab → alt-bab quruluşunda
- Ərəbcə mətn, azərbaycanca tərcümə, mənbə istinadı və qeydlər
- Bütün kitabxananı oflayn oxumaq üçün yüklə, öz keş təmizləməsi ilə
- Ayrıca görünüş ayarları: ərəb şrifti (Noto Nəsx, Osman Taha və ya Ayət), mətn
  ölçüləri, ərəbcə / tərcümə / mənbə açarları
- Əlfəcinlər, oxuma tarixçəsi, kolleksiya daxili naviqasiya və axtarış

### Səs və qiraət

- Seçilmiş qarilərdən ayə-ayə qiraət, oxuyucuda ayə izləmə ilə
- Arxa fonda oxutma — media bildirişi, qulaqlıq idarəetməsi və Android Auto
- Oxutma sürəti, ayə və aralıq təkrarı, səs bitəndə davranışın seçilməsi
- Oflayn dinləmək üçün qiraətlərin və sözbəsöz səsin yüklənməsi

### Axtarış

- Ərəbcə ayələr, tərcümələr, surə adları və hədislər üzrə tam mətn axtarışı
- Filtrlər, sürətli keçidlər və axtarış tarixçəsi
- Səsli axtarış (Android)

### Kitabxana və şəxsi məlumatlar

- Həm ayələr, həm hədislər üçün qeydli əlfəcinlər
- Quran və hədis üçün ayrıca oxuma tarixçəsi
- Günün ayəsi (və ya hədisi), ixtiyari günlük xatırlatma bildirişi ilə
- Ana ekran vidjetləri: Günün ayəsi və qiraət pleyeri
- Ayarların və əlfəcinlərin ixracı və idxalı
- Yüklənmiş tərcümələr, qiraətlər və xətt şriftləri üçün yaddaş təmizləmə

### Paylaşma

- Ayələri və hədisləri mətn kimi (mesajlaşma tətbiqlərinə uyğun formatla) və ya
  daxili şəkil redaktoru ilə şəkil kimi paylaş

### Görünüş və dil

- İşıqlı / qaranlıq / sistem mövzusu, yeddi vurğu palitrası və Android 12+
  üzərində Material You dinamik rəngləri
- Tətbiq dilləri: azərbaycan, ingilis, rus və türk (üstəgəl sistem dili),
  seçilə bilən latın / ərəb rəqəmləri ilə

## 🔨 Necə qurulur

Android SDK və JDK 17+ tələb olunur.

```bash
git clone https://github.com/cafarovceyxun/AnaMuslim.git
```

Gradle-ı Android SDK-nıza yönləndirin:

```bash
echo "sdk.dir=/path/to/Android/sdk" > local.properties
```

Debug APK qurun:

```bash
./gradlew :app:assembleDebug
```

APK `app/build/outputs/apk/debug/` qovluğuna düşür. Debug buraxılışları Play
Store versiyası ilə *yanaşı* quraşdırılır — onlar
`com.cafarovceyxun.anamuslim.test` tətbiq id-sindən istifadə edir, yəni gündəlik
işlətdiyiniz nüsxəyə toxunulmur.

> **Qeyd:** `local.properties` maşına aiddir və heç vaxt commit olunmamalıdır.
> Buraxılış imzalanması `keystore.properties` vasitəsilə qurulur —
> [keystore.properties.example](keystore.properties.example) faylına baxın.

iOS üçün əvvəlcə Gradle sinxronizasiyası edin, sonra `iosApp/iosApp.xcodeproj`
faylını Xcode-da açın. Hədəfdə hələ boşluqlar var — nəyin ortaq olduğu və nəyin
qaldığı [IOS_MIGRATION_PLAN.md](IOS_MIGRATION_PLAN.md) faylındadır.
